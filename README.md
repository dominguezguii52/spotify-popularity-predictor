An exploratory data analysis (EDA) and machine learning project investigating whether a track's audio features can predict its popularity on Spotify.

---

## 📊 Project Overview
Many believe that creating a "hit" song is just a matter of hitting the right audio metrics (such as high energy, danceability, or a specific tempo). This project puts that assumption to the test using a Spotify dataset, Python, and Scikit-Learn.

## 🛠️ Tech Stack
* **Language:** Python
* **Libraries:** Pandas, Scikit-Learn, Matplotlib, Seaborn
* **Version Control:** Git & GitHub

## 📈 Key Findings & Insights
* **The Audio Myth:** A Simple Linear Regression model yielded an **$R^2$ Score of ~0.016**, proving that audio features alone have almost **no direct correlation** with a track's popularity.
* **The Real Drivers:** Popularity is primarily driven by external factors such as artist identity, strategic marketing, genre trends, and collaborations rather than raw acoustic metrics.
* **Top Performing Genres:** Pop and K-Pop dominate the highest average popularity rankings.
